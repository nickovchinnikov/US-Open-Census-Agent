# US Open Census Data: Data Overview

## Purpose and scope

`US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET`, provides US Census measures at the **Census Block Group (CBG)** level. It is designed for neighbourhood-scale analysis rather than for a single pre-built report. A question may require selecting a Census measure, filtering or aggregating CBG records, and translating geographic codes into names.

The exploration identified parallel data releases for **2019** and **2020**. The main 2019 CBG tables contain about **220,333 rows**; the corresponding 2020 tables contain about **242,335 rows**. Within a release, the main Census tables share the same row count, which is consistent with one record per CBG in each table.

## Data structure

The dataset is split into thematic Census tables instead of one wide table:

```text
2019_CBG_B01, 2019_CBG_B02, 2019_CBG_B03, ...
2020_CBG_B01, 2020_CBG_B02, 2020_CBG_B03, ...
```

Each table uses `CENSUS_BLOCK_GROUP` as the geographic identifier. Table codes such as `B01` are families of Census variables; the full variable code identifies an individual measure. For example, `B01001` is the *Sex by Age* table.

The dataset covers considerably more than population. Its table families support analysis of demographic, household, housing, income, employment, education, race, age, and sex measures, among others. Available measures should always be confirmed through the supplied metadata rather than inferred from a table name.

## Key terminology

| Term | Meaning | Example |
| --- | --- | --- |
| **Census Block Group (CBG)** | A small Census statistical geography used as the dataset's base unit. It is a subdivision of a Census tract. | One `CENSUS_BLOCK_GROUP` value represents one area. |
| **Census table** | A related group of Census measures, stored here in a table such as `2019_CBG_B01`. | `B01001` = *Sex by Age*. |
| **Census variable / field** | One precisely defined measure within a Census table. | `B01001e10`. |
| **Estimate (`e`)** | The reported value of a measure. | `B01001e1` is the total-population estimate. |
| **Margin of error (`m`)** | The uncertainty reported alongside an estimate. | `B01001m1` is the margin of error for `B01001e1`. |
| **Universe** | The population to which a table or measure applies. | *Total population* is the universe for the age-and-sex example. |
| **FIPS code** | A standard geographic code used to identify states and counties. | State and county FIPS codes can be mapped to names such as `AL` and `Autauga County`. |

## Example: interpreting a field

The table `2019_CBG_B01` contains columns such as:

```text
CENSUS_BLOCK_GROUP
B01001e1, B01001m1
B01001e2, B01001m2
...
```

The metadata resolves the compact code into meaning. For example:

```text
B01001e10
  table title: Sex by Age
  topic:       Age and Sex
  universe:    Total population
  hierarchy:   Male → 22 to 24 years
```

Thus, `B01001e10` is the estimated number of males aged 22–24 in a CBG. The same pattern makes the metadata necessary for selecting the right field; variable names alone are not sufficiently readable or safe for natural-language analysis.

## Metadata and geography layers

The dataset includes a built-in data dictionary:

```text
2019_METADATA_CBG_FIELD_DESCRIPTIONS
```

Its fields include `TABLE_ID`, `TABLE_NUMBER`, `TABLE_TITLE`, `TABLE_TOPICS`, `TABLE_UNIVERSE`, and `FIELD_LEVEL_1` through `FIELD_LEVEL_10`. Together, these fields express both the definition and hierarchy of a Census variable. This is the authoritative semantic reference for connecting a human concept to a dataset column.

Geography is provided separately:

```text
2019_METADATA_CBG_GEOGRAPHIC_DATA  — CBG identifier, land/water area, latitude, longitude
2019_METADATA_CBG_FIPS_CODES       — state and county FIPS codes and names
```

The geographic table supports spatial analysis, while the FIPS table supports human-readable state and county labels. The exact CBG-to-state/county join path still needs to be verified before it is used in an analysis.

## Working rules

- Use the release year consistently: do not combine 2019 and 2020 values without an explicit comparison design.
- Use estimate fields by default; include margins of error when uncertainty is requested or materially affects interpretation.
- Resolve a variable through field metadata before writing analytical SQL.
- Treat CBG values as area-level measures. Totals across a larger geography require an explicit aggregation and a verified geographic mapping.

## Boundary of this step

This step documents the available data and its vocabulary only. The next experiment will test whether a free-form human question can reliably retrieve the correct Census variable from metadata—for example, whether “How many males aged 22 to 24 are there?” resolves to `B01001e10`.

## Queries

```sql
SHOW DATABASES;
SHOW SCHEMAS IN DATABASE US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET;

SHOW TABLES IN DATABASE US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET;

SHOW VIEWS IN DATABASE US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET;

SELECT
    table_name,
    row_count,
    bytes
FROM US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.INFORMATION_SCHEMA.TABLES
WHERE table_schema = 'PUBLIC'
ORDER BY table_name;

DESCRIBE TABLE
US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.PUBLIC."2019_CBG_B01";

DESCRIBE TABLE
US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.PUBLIC."2019_METADATA_CBG_FIELD_DESCRIPTIONS";

SELECT *
FROM US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.PUBLIC."2019_METADATA_CBG_FIELD_DESCRIPTIONS"
LIMIT 10;


SELECT *
FROM US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.PUBLIC."2019_METADATA_CBG_FIELD_DESCRIPTIONS"
WHERE TABLE_NUMBER = 'B01001'
ORDER BY TABLE_ID;

DESCRIBE TABLE
US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.PUBLIC."2019_METADATA_CBG_GEOGRAPHIC_DATA";

SELECT *
FROM US_OPEN_CENSUS_DATA_NEIGHBORHOOD_INSIGHTS_FREE_DATASET.PUBLIC."2019_METADATA_CBG_FIPS_CODES"
LIMIT 20;
```
